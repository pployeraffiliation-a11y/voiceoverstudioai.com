VoiceOverStudioAI — Monochrome Favicon Pack (black/gray/white)

1) Upload the folder "icons" to:
   /icons/

2) Upload these to the site root:
   /site.webmanifest
   /browserconfig.xml

3) Paste this inside <head> on ALL pages:

<link rel="apple-touch-icon" sizes="180x180" href="/icons/apple-touch-icon.png">
<link rel="icon" type="image/png" sizes="32x32" href="/icons/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/icons/favicon-16x16.png">
<link rel="icon" href="/icons/favicon.ico">
<link rel="manifest" href="/site.webmanifest">
<link rel="mask-icon" href="/icons/safari-pinned-tab.svg" color="#ffffff">
<meta name="msapplication-TileColor" content="#0b0b0c">
<meta name="msapplication-config" content="/browserconfig.xml">
<meta name="theme-color" content="#0b0b0c">
