## 2) Diagnostic (ce qui explique le “1 clic / 1 645 impr.”)

1. **Positions “milieu de page 1” (6–9)** sur les pages qui génèrent le plus d’impressions → CTR mécaniquement faible.
2. **Intent** : une partie des requêtes est orientée “docs / updates” (API) et “pricing” (DE). Les pages existent, mais Google peut encore tester leur pertinence.
3. **Problème de canonicalisation `.html`** : GSC montre des impressions sur des URLs en `.html` (ex: `/blog/ai-voiceover-2026-es.html`, `/blog/index.html`). Même avec canonical, c’est un bruit SEO inutile qui peut ralentir la consolidation.

## 3) Audit SEO technique (repo)

### OK

- `robots.txt` et `sitemap.xml` sont générés via routes Next (`app/robots.ts`, `app/sitemap.ts`).
- Balises SEO par page : `title`, `description`, canonical, `hreflang` (via `alternates.languages`), OpenGraph/Twitter.
- Données structurées : `Article` + `BreadcrumbList` + `FAQPage` (si FAQ).

### À corriger / améliorer

- **Sitemap** : les pages `noindex` ne devraient pas être incluses dans le sitemap.
- **URLs `.html`** : en export statique, les fichiers `.html` restent accessibles et peuvent être indexés si non redirigés.
- (Optionnel) **Schema “Article”** utilisé aussi pour des pages qui ne sont pas des articles (ex: hub blog, pages légales) → mieux de différencier `WebPage`/`CollectionPage` vs `Article`.
- (Optionnel) `lang` HTML est initialement `en` dans le HTML statique (puis corrigé côté client). Pour du SEO multilingue “propre”, l’idéal est un `lang` serveur‑side par route.

## 4) Quick wins appliqués dans le code (déjà faits)

- `app/sitemap.ts` : **exclusion des pages `noindex` du sitemap**.
- `public/_redirects` : **redirections 301 “.html → URL canonique”** ajoutées pour les pages manquantes (blog posts + pages racine), afin d’éviter l’indexation des variantes `.html`.
- Hub blog : **suppression du `noindex`** sur `/blog/` + hubs traduits (`/blog/index-fr`, `/blog/index-de`, `/blog/index-es`) pour débloquer impressions sur requêtes “broad”.
- Pages d’accueil (`app/page.tsx`, `app/index-fr/page.tsx`, `app/index-de/page.tsx`, `app/index-es/page.tsx`) : **métadonnées** plus orientées “ElevenLabs / voiceover / dubbing 2026” (meilleur alignement snippet).

À déployer pour effet SEO : push + build Netlify (ou pipeline équivalent).
