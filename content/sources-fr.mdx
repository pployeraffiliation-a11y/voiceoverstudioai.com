# Sources

Nous visons une information claire et actionnable. Principales catégories de sources :

- Pages produit et documentation officielles (fonctionnalités, limites, prix)
- Notes de mise à jour / changelogs quand disponibles
- Documentation API
- Retours pratiques sur les workflows (pièges, réglages)

Pour Pictory AI, les pages s’appuient notamment sur les pages officielles de fonctionnalités, pricing, release notes et centre d’aide AI Credits. Les montants, quotas et promotions pouvant changer, les articles invitent à vérifier le checkout officiel avant achat.

Si vous repérez une erreur, contactez-nous avec l’URL : [Contact](/contact-fr).
