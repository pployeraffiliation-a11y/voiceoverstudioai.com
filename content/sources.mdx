# Sources

We aim to keep content accurate and actionable. Here are the main source types we rely on:

- Official product pages and documentation (features, limits, pricing)
- Changelogs / release notes when available
- API documentation and SDK references
- Practical workflow feedback (common pitfalls, configuration tips)

For Pictory AI, we rely on official feature pages, pricing pages, release notes and AI Credits help center articles. Because prices, quotas and promotions can change, Pictory pages ask readers to verify the official checkout before purchasing.

If you spot an issue, contact us with the page URL and details: [Contact](/contact).
